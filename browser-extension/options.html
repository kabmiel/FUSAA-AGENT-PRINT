Utilisation

  1. Dans FUSAA, ouvrez Arrivées et créez un code de liaison.
  2. Ouvrez l’icône FUSAA dans Brave, collez le code, puis associez le navigateur.
  3. Gardez WhatsApp Web ouvert. Les nouvelles arrivées apparaissent dans Arrivées.

Confidentialité

L’extension détecte des marqueurs visuels de message non lu et de bulle entrante. Elle n’extrait pas le texte des messages, les contacts, numéros, médias, fichiers, cookies ou session WhatsApp.

Elle communique uniquement avec le serveur FUSAA local 192.168.1.68:8000, au moyen d’un code à usage unique. Chaque arrivée envoyée contient seulement un identifiant aléatoire, le type d’alerte et un compteur.
