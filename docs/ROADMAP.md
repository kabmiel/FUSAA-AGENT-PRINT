# Roadmap

1. **Foundation (implemented):** core entities, migrations, JWT, organization membership, confirmation gate and audit.
2. **Local Agent (implemented for the first milestone):** enrollment, WSS notifications plus HTTPS fallback, durable queue, backoff, Windows discovery, spooler tracking and cancellation where supported.
3. **Print Core (implemented for the first milestone):** upload, PDF/image inspection, derived preview, print settings, explicit confirmation, document/job history, cancellation and responsive UI.
4. **PWA/realtime (implemented for the first milestone):** installable PWA, authenticated realtime events, cache shell, offline upload queue and configurable Web Push.
5. **AI assistant (implemented for the first milestone):** provider-neutral interface, allow-listed tool layer, deterministic intent baseline, confirmation levels and auditable actions.
6. **Document processing (implemented for the first milestone):** non-destructive transforms, deterministic A4/A3/A5 layout sheets, derived PDFs and new PrintJobs from prepared documents.
7. **Connectors (implemented for the first milestone):** normalized incoming documents, API and email intake endpoints, idempotent connector events, secure connector keys and isolated WhatsApp abstraction.
8. **Business (implemented for the first milestone):** customers, catalogue, deterministic price rules, cost estimates, invoice drafts, payments and business statistics.
9. **Multi-site (implemented for the first milestone):** workshop roles, centralized supervision, stale-agent detection and auditable job routing.
