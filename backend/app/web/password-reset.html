RÉCUPÉRATION LOCALE FUSAA

Nouveau mot de passe

Le lien privé est valable 15 minutes et s’utilise une seule fois.

Vous avez oublié le mot de passe ?

Si vous êtes administrateur, ouvrez PowerShell dans le dossier de FUSAA sur votre PC puis lancez :

.\scripts\recover-admin.ps1

Indiquez votre e-mail administrateur, puis ouvrez le lien privé affiché. Aucun service mail n’est nécessaire. Pour un compte hébergé, la récupération se fait depuis la console autorisée du serveur, pas depuis une base locale différente.

Pour un autre compte, demandez à l’administrateur de créer un lien depuis le menu Équipe.
